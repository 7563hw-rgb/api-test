# 🧭 HapticBelt: 12채널 웹 기반 햅틱 내비게이션 복대
> **시각장애인의 보행 생존성 극대화 및 인지 부하 감소를 위한 분산 엣지 컴퓨팅 기반 보조 기기**

## 🌟 프로젝트 배경 및 핵심 가치
본 프로젝트는 기존 시각장애인용 보행 보조 기기(음성 안내 앱, 초음파 스마트 지팡이 등)가 가지는 치명적인 한계인 **'청각 마스킹(Auditory Masking)'**과 **'신체 좌표계 왜곡'** 문제를 공학적으로 해결하기 위해 기획되었습니다.

1. **100% 청각 자원 개방:** 음성 안내를 배제하고 오직 '복부의 촉각' 채널만 점유하여, 사용자가 다가오는 차량 등 주변 위험 소음을 완벽히 인지하며 걸을 수 있습니다.
2. **절대 신체 좌표계 구축:** 인체의 무게중심(Core)인 허리에 9축 IMU 센서를 밀착시켜, 팔이나 고개의 움직임에 방해받지 않는 흔들림 없는 타겟 방위를 유도합니다.
3. **접근성 및 분산 연산:** 네이티브 앱 설치가 필요 없는 Web BLE 클라이언트를 채택하였으며, 무거운 공간 수학 연산은 스마트폰(웹 엔진)에 외주를 주어 시스템을 경량화했습니다.

## ⚙️ 하드웨어 아키텍처 (Hardware Architecture)
안정적인 PWM 제어와 메인보드 보호를 위해 **'연산 - 신호 제어 - 전력 구동'** 역할을 완벽히 분리한 3단계 아키텍처를 설계했습니다.

* **MCU (ESP32):** Web BLE 무선 통신 및 BNO085 센서 쿼터니언 데이터 수집, 메인 연산 전담.
* **Sensor (BNO085):** 9축 IMU 퓨전 센서. 지구 자기장과 자이로를 결합하여 사용자의 절대 방위각(Heading)을 0.01초 단위로 추출.
* **Motor Driver (PCA9685):** 16채널 PWM 코프로세서. ESP32의 타이머 부하를 덜어주어 12개의 모터에 지터(Jitter) 없는 독립적인 펄스를 제공.
* **Amplifier & Protector (ULN2003):** 모터 구동용 고전류 증폭기. 내장된 플라이백 다이오드로 역기전력(Inductive Kickback)을 차단하여 메인보드 소각 방지.
* **Actuators:** 12개의 코인형 진동 모터(ERM). 360도를 30도 간격으로 쪼갠 12방위 고해상도 촉각 렌더링 수행.

## 💻 소프트웨어 및 핵심 알고리즘 (Software & Core Algorithms)

### 1. 비동기 Web BLE 프론트엔드 (스마트폰)
* Tmap API를 연동하여 경로(GeoJSON)를 파싱하고 위치를 추적하는 **관제탑** 역할을 수행합니다.
* 시각장애인의 접근성을 고려하여 화면 UI 시각화뿐만 아니라, **웹 접근성(a11y) 표준 및 스크린 리더(VoiceOver/TalkBack)** 호환성을 확보했습니다.

### 2. 거울 효과 상쇄 알고리즘 (Mirror-Effect Cancellation)
Tmap의 방위각(시계 방향)과 BNO085의 회전각(반시계 방향) 간의 이질적인 극성을 융합하기 위한 핵심 수학 모델입니다.
```cpp
// 목표 각도와 센서 각도를 가산(+)하여 극성을 상쇄하고, 
// 360도 모듈러 연산으로 목표 타겟을 절대 공간에 고정(원형 정규화)
float relativeAngle = targetAngle + currentHeading;
while (relativeAngle >= 360.0) relativeAngle -= 360.0;
while (relativeAngle < 0.0) relativeAngle += 360.0;
